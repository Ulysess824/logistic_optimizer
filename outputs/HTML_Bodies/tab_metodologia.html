Detour: Kilómetros extra mínimos.
Backhauling Eficiente: Máxima utilidad de retorno.

Fundamentación Algorítmica: GLS

Referencia: Voudouris, C., & Tsang, E. P. K. (1999)

1. Función de Objetivo Aumentada (h)

h(s) = g(s) + λ · ∑i ∈ F (pi · Ii(s))
  • g(s): Métrica de coste base (Distancia real de flota).
  • λ: Hiper-parámetro que regula el peso de las penalizaciones.
  • pi: Vector de penalización acumulado para cada conexión (i).
  • Ii(s): Binario que activa el castigo si el arco i está en el plan actual.

2. Criterio de Perturbación (Utilidad)

Util(s, i) = Ii(s) · [ ci(s) / (1 + pi) ]
El solver identifica los arcos que maximizan esta utilidad para aplicarles un incremento en su penalización. Este mecanismo asegura que el sistema castigue preferentemente conexiones costosas que no han sido exploradas exhaustivamente, garantizando el escape de óptimos locales y la convergencia hacia soluciones de mayor ahorro energético.
